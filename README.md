# 运动会成绩实时统计与大屏展示系统（联网版 v2）

现场多台手机/电脑同时录成绩 → 大屏实时出榜。**零依赖**（只用 Node 内置模块与内置 SQLite），
前端零框架零构建，**断外网照常用**。

```
大屏（免登录只读）   http://你的局域网地址:8080/screen      ← 投到电视/拼接屏
后台管理             http://你的局域网地址:8080/admin
                     （手机浏览器打开同一个地址就能录成绩，不用另开页面）
成绩单打印           http://你的局域网地址:8080/print
```

后台按账号区分：

| 账号 | 能干什么 | 改动怎么生效 |
| --- | --- | --- |
| **管理员** | 全部功能（含账号、备份、恢复、规则设置） | 改动先进「暂存区」，点**确认修改并推送大屏**才落盘（可以先预览） |
| **操作员** | 录成绩、检录、改名单/赛程、发公告、聊天 | **立刻生效**，不用确认 |
| **只读** | 只能看（成绩与名次、公告、聊天室、班级总分） | 不能改 |

## 一键部署（推荐：老师只需双击一次）

**在那台要当服务器的电脑上，双击 `一键部署.bat`，就完事了。**

它会自己依次做完这些事，每一步都打印中文结果：

| 步骤 | 做什么 | 出问题会怎样 |
| --- | --- | --- |
| 1 | 检查 Node.js 版本（需要 22.5 以上） | 没装或版本太低 → 直接告诉你怎么办 |
| 2 | **没装 Node.js 就自动下载一份便携版**放进 `node\` 目录 | 下载不了 → 打印手动安装的三步说明 |
| 3 | 检查项目文件是否完整 | 缺文件会点名是哪个 |
| 4 | 检查端口是否被占用 | 已被占用会说明是"本系统已经在跑"还是别的程序 |
| 5 | 准备 `data\` 目录并确认**可写** | 不可写会提醒你把文件夹移到 D:\ 或 F:\ |
| 6 | **放行防火墙**（让手机能连上） | 不是管理员 → 打印可粘贴的 `netsh` 命令 |
| 7 | 打印**手机该输的网址**（自动跳过 VMware/Radmin 等虚拟网卡） | 找不到局域网地址会提醒先连网 |
| 8 | 启动服务 | 起不来会列出三个最常见原因 |

> **建议右键 → 以管理员身份运行**：只有"放行防火墙"这一步需要管理员权限。
> 不放行也能用，但手机连不上（电脑上打得开）。

部署完，那台电脑上会多出这几个双击入口：

| 双击 | 作用 |
| --- | --- |
| `一键部署.bat` | 完整部署（第一次用这个） |
| `启动.bat` | 日常启动（跳过部署检查，快） |
| `停止.bat` | 停止服务，释放端口 |
| `防火墙放行.bat` | 单独放行防火墙（会自动申请管理员权限） |
| `开机自启.bat` | 设置/取消"开机自动启动"（**点一次开、再点一次关**） |
| `我的地址.bat` | 打印本机所有网址 + 连不上的排查顺序 |
| `重置口令.bat` | 忘了口令时用 |

**拷到别的电脑**：整个文件夹拷过去，在那边双击 `一键部署.bat` 即可 ——
那边没装 Node 的话会自动下载。数据和名单都在 `data\` 目录里，一起拷走。

**手机打不开？** 双击 `我的地址.bat`，它会列出地址并给出排查顺序（防火墙、专用网络、虚拟网卡）。

**忘了口令？** 双击 `重置口令.bat`（在服务器那台电脑上）：它会先列出所有账号，
然后问你「要重置哪个账号」和「新口令」，输入两遍就改好了（至少 6 位）。
改完**关掉服务窗口重新双击 `启动.bat`**，再用新口令登录。

**口令在哪里看？** 两个地方，都在同一台服务器上：

1. **黑窗口里当场显示**（`重置口令.bat` 跑完最后几行，或首次 `启动.bat` 的启动横幅里）
2. **项目目录下的 `口令.txt`** —— 上面两处都会顺手写一份，所以当时没抄、窗口关了也还能翻出来。
   每次重置口令都会**覆盖**这个文件；抄走之后建议把它删掉（别留在公用电脑上）。

> 会命令行的也可以用：`node tools/reset-password.js admin 新口令`；
> 加 `--admin` 还能顺便把账号恢复成「启用的管理员」（账号被停用或降权时用）。
> 不带任何参数运行则列出账号并进入问答式重置。
>
> 只想体检不改任何设置：`node tools/deploy.js --check`

**改端口**：用记事本打开 `config.js`，改 `port`，保存后重启
（重启后防火墙要重新放行一次，双击 `防火墙放行.bat` 即可）。

## 现场怎么用（最短路径）

| 场景 | 去哪 |
|---|---|
| 先把名单弄进去 | 后台 → 名单 / 导入与设置 → **导入名单**（从 Excel 选中整块复制粘贴最省事；也能选 .csv / .tsv / .txt）<br>如果学校发的是整份「代表队名单」Word 文档，用 `node tools/load-roster.js "名单.docx" --write` 一次录完 |
| 比赛结束，明年还用这份名单 | `node tools/reset-meet.js --write` —— 清掉成绩/检录/聊天，**保留名单、班级、项目、报名、账号** |
| 把系统交给别人 / 彻底重来 | `node tools/reset-meet.js --write --full` —— 上面那些**再加**：清掉其它账号、备份历史、手工公告；会额外留一份 `BEFORE-CLEAR` 安全备份 |
| 想在别的机器/服务器上试功能、又怕弄乱数据 | `node tools/make-test-copy.js` —— 在**旁边**生成一份独立的测试版（自己的假名单、自己的库），原目录一个文件都不动 |
| 排项目与时间 | 后台 → 赛程 → 新增项目（可设开始/结束时间，到点自动变"进行中/已结束"） |
| 裁判录成绩 | 后台/赛程里每个项目后面的 **名单/录入** 按钮 → 手机上打开，输入框点一下改完、**点到别处自动保存** |
| 检录 | 录入页项目卡上的"开始检录"；或后台 → 检录（开始/停止会自动写一条公告）。**大屏不再显示检录栏** —— 检录台看后台那一页更清楚 |
| 发通知 | 后台 → 公告（标"重要"的会在大屏顶部大字滚动） |
| 看总分 | 大屏右下「班级总分榜」，按 初一→初二→初三→高一→高二→高三 轮流翻页 |
| 导 Excel | 后台 → 导入与设置 → **导出与备份**（成绩汇总表 / 成绩明细 / 排名表 / 班级总分榜 / 名单 / 秩序册 / 检录单） |
| 打印成绩单 | 后台 → 成绩 → 打印成绩单（A4，带裁判长签字栏） |

### 成绩怎么填

| 填什么 | 含义 |
|---|---|
| `12.35` | 12.35 秒（径赛） |
| `2:15.30` | 2 分 15.30 秒 |
| `1:02:15.30` | 1 小时 2 分 15.30 秒 |
| `5.67` / `5.67米` | 5.67 米（田赛） |
| **`犯规`** / `X` / `×` / `F` | **犯规**：显示"犯规"，**排在榜尾、不计分**，人仍留在榜上 |
| `弃权` / `受伤` / `退赛` / `DNS` / `-` | **弃权**：显示"弃权"，同样排榜尾、不计分 |
| **清空输入框** | 删除这条成绩 |

> **「犯规」和「弃权」是两回事，显示必须分开**（老师一眼就能看出差别）：
> - 田赛**每次试跳单独判**：某一次犯规就在那一格填「犯规」，其余照填成绩，名次取最好的一次
> - 三次全犯规 → 汇总显示「犯规」（不是"弃权"）
> - 径赛被判犯规 → 这一次填「犯规」，显示「犯规」
> - 名次上两者一样：都在榜尾、都不计分、彼此并列
>
> 录入页每个成绩框右边就有「**犯规**」「**弃权**」两个按钮，点一下等于填进去并立刻保存，
> **再点一次取消**（不用手删）。现场打这两个字容易打成"犯规了"，手机上还要切输入法。

**输错了会明确报错**，绝不会把 `12.35mm` 悄悄当成 12.35 秒。

### 排序与名次规则（一届届磨出来的，别改）

- 径赛**越小越靠前**；田赛**越大越靠前**
- 并列用**标准竞技排名 1,2,2,4**。**"相等"按项目的计时精度判**（不是"差不超过某个数"）：
  百分位下 12.34 与 12.34 并列、12.01 与 12.02 **不**并列；千分位（终点摄像）下
  12.341 与 12.342 是两个人；手工计时选十分位、整秒计时选整秒。
  精度是**每个项目**的属性，在「赛程编排 → 详细设置 → 计时/计量精度」里选
- 并列时排序稳定：先比号码（小的在前、没号码排后），再比姓名 —— 否则同成绩的人每次刷新都换位置
- 田赛可记 3 次试跳，**名次取最好一次**；大屏只显示最好成绩
- **4×100 接力按班级排名**，班级名下面用小字列出本次参赛的 4 名队员（队员姓名存快照，删人也不影响历史成绩单）
- 班级总分榜：只统计**已结束**项目的名次分，计分表 **7 / 5 / 4 / 3 / 2 / 1**（取前六名；第 2 名是 5 分，不是连续递减），
  并列名次各得该名次全额分（1,2,2,4 → 7,5,5,3）；接力分数记到班级、**得分 ×2**
  （接力一个项目只算一条成绩，却要出动 4 名队员，所以名次分翻倍给；接力第 1 名 = 7×2 = 14 分。
  倍数在后台 → 导入与设置 → 计分规则里可改，想不翻倍就选"接力和单项一样"）
- **班级总分的名次按年级分开排**：大屏按年级翻页，每一页显示的是**该年级内**的第 1、2、3…名
  （初一和初三拿同样分数含金量不同，混在一起排没意义）。
  导出「班级总分榜」是全校总排名；点「只看这个年级」导出的则是该年级内排名
- 预赛 → 决赛：预赛那一行点「录取决赛」，**建出决赛项目并按预赛名次预填一份起点名单**
  （并列跨录取线的一起预填，不抽签淘汰）。这份名单只是起点 ——
  谁最终进决赛到「名单」页增删即可（现场常有例外：有人预赛完就走了、接力要换棒次）。
  名次照旧只按**决赛**成绩算，预赛成绩不会带进来。
  已生成过决赛不会重复生成；决赛**已经录了成绩**时，重做会被拒绝（免得把现场干过的活抹掉）
- 一个运动员在一个项目只算一条成绩（同一次试跳重复提交只落一条）
- **报名数据按"名单口径"保留，不做超限清理**（有意决定，别当脏数据看）：
  秩序册的「项目分组表」会按"每项每班限报 2 人"把超限的报名剔除（共 34 个报名项次、
  涉及 30 人，例如初一1班男子 400 米有 4 人报名、只编排了 2 人）。
  系统里**这 34 条报名一律保留**，理由：
  · 报名是"网上报名系统"的原始事实，删了就再也对不上账
  · 大屏和名次只按**实际录到的成绩**算，没编排的项次本来就不会产生成绩，
    留着不会让任何榜单出错
  · 现场临时要放人进来时，报名已经在名单里，直接录成绩即可
  同理，**接力队人数不足 4 人也照原样保留**（高一42班女子、高三36班女子、
  高三37班男子、高三40班女子各只有 3 人——报名时就是 3 人）。系统不拦，
  现场缺人时补报一个即可；不补也能照常检录和录成绩。

## 大屏

版面参照学校官方颁奖屏（深藏蓝 + 金）：

```
┌────────────────────────────────────────────────┬──────────────┐
│ 校徽 会名/日期      「正在进行」条        大时钟 │              │
├────────────────────────────────────────────────┼──────────────┤
│ 成绩公告（多张项目卡片并排）                    │ 赛程安排      │
│  卡片：项目名 + 组别/场地 + 名次行               │  正在比 / 马上 │
│  名次徽标金/银/铜，成绩是金色等宽数字            │  要检录 / 刚结束│
│                                                 ├──────────────┤
│                                                 │ 班级总分      │
├────────────────────────────────────────────────┴──────────────┤
│ 公告（多条轮播，过长自动滚动）    显示模式 / 刷新 / 全屏       │
└───────────────────────────────────────────────────────────────┘
```

- **前三名**金/银/铜圆角徽标；并列显示同一个名次；弃权显示「弃权」并排在榜尾
- **接力**：姓名位显示班级，下面用小字列出本班参赛的 4 名队员
- **赛程安排只显示该关心的**：全部的"进行中/检录中" + 接下来 6 个（按开始时间）
  + 刚结束的最近 3 个（压暗显示）。每条带**相对时间**（"还有 5 分钟""12 分钟前结束"）。
  不再列 140 个项目的整本秩序册
- 班级总分榜按年级（初一→初二→初三→高一→高二→高三）轮流翻页，
  **每一页是该年级内的排名**（第 1 名从每个年级各自算起）
- 一屏放不下时**只有那一栏自己滚**（原生滚动 + 平滑动画，栏目外的行不参与绘制），
  栏目翻页要**等它滚完**才走。成绩卡与班级总分都会滚，一条都不会看不到
- 每栏起始时间**互相错开**；面板角上有**独立暂停**按钮（❚❚）
- 滚动节奏统一在 `screen.js` 顶部的 `TIMING` 里（现场觉得快慢不合适就改那里），
  并按显示模式微调
- 底部**只有一条公告横幅**，没有工具栏；右下角有一组悬浮控件（显示模式 / 继续翻页 /
  刷新 / 全屏），鼠标静止 5 秒自动淡出、动一下就回来，平时不占版面
- 重要公告是顶部红色大字滚动条，可手动关闭
- 显示模式：标准 / 户外大 / 户外特大（户外档提亮对比度、加大安全边距）

**多比例屏幕适配**（不写死断点，都是量出来的）：

- 所有尺寸 = 设计像素 × `--s`，`--s` 由屏幕短边与长宽比算出 —— 4K、1366×768、21:9 超宽、竖屏拼接墙都试过
- 成绩区的卡片列数按实测宽度定；右侧三条各自按高度决定放几条
- 卡片高度按实际可用空间分配、名次行严格封顶，**宁可少显示几行也不裁切、不重叠**

页面会**自己体检版面**（文字重叠/溢出/被裁切/JS 报错），结果写进 `#layout-report`
并回报服务端（日志里搜 `[页面问题]`）。界面上**没有单独的"体检"页签**了；
想看细节就在浏览器控制台执行 `App.checkLayout('admin')` 或 `App.checkLayout('screen')`。

## 后台

亮色皮肤（白底浅灰卡片 + 深色顶栏 + 品牌金标题）：

```
┌──────────────────────────────────────────────────────────────┐
│ 校徽 运动会计分·录入后台  本届名称  连接状态 打开大屏 账号 退出 │
├──────────────────────────────────────────────────────────────┤
│ 待确认 N 项  查看待确认 预览效果 放弃全部改动 确认修改并推送大屏│
├──────────────────────────────────────────────────────────────┤
│ 成绩录入｜赛程编排｜运动员名单｜导入与设置 ｜成绩与名次｜班级总分…│
├───────────────────┬──────────────────────────────────────────┤
│ 比赛项目           │ 女子800米决赛       未开始 进行中 已结束  │
│  进行中(2)         │ 组别 · 时间 · 场地 · 状态                 │
│   女子800米决赛    │ 已录入 5 / 10                             │
│  未开始(3) …       │ ┌ 初一(2班) ────────────────── 2 人 ─┐   │
│  已结束(6) …       │ │ 5  107 赵萱  初一(2班) [182.38] 清空│   │
│                    │ │ 2  108 马欣  初一(2班) [168.64] 清空│   │
└───────────────────┴──────────────────────────────────────────┘
```

- 左边点项目切换；右边是该项目录入表，**按班级分块**、带班级小标题与人数
- 成绩框有值时自动变**浅绿**，填错变红，断网待补交变琥珀色
- 每行右侧：○/✓ 一键标记检录到场 + 「清空」
- **没有零散的"保存"按钮**：输入框改完离开就自动提交，回车跳下一个还空着的人
- **改完立刻在界面上看到**，不用按 F5：写操作成功会主动重画当前页并拉最新数据
- 顶部**暂存条**（只有管理员看得到）：待确认 N 项 / 查看待确认 / **预览效果** / 放弃全部改动 / **确认修改并推送大屏**
- 暂存期间显示的是"**确认后会变成什么样**"；预览跑在**数据副本**上，真实数据零污染
- 确认时是**单事务**：任何一项失败就整体回滚（不会变成半成品），并列出失败原因
- 页签（常用的排左边，**按角色显示**）：成绩录入 / 检录 / 成绩与名次 / 公告 / 聊天室 / 赛程编排 /
  运动员名单 / 导入与设置 / 班级总分 / 备份与导出 / 账号 / 操作记录
  （操作员看不到导入与设置/备份/账号/操作记录，只读只看得到成绩与名次/公告/聊天室/班级总分）
- **每个项目后面都有「名单/录入」入口**，点了直接切到该项目的录入页签
- 名单页：搜索（姓名/号码）+ 组别/年级/班级三重筛选；排序 组别→年级→班级→号码→姓名；**同班成块显示**
- 名单页点「**报名 N 项**」展开：看得到这个运动员报了哪些项目、可以**加项目 / 取消报名**
  （已经录了成绩的项目不给删，避免连成绩一起删掉）
- 名单导入在「导入与设置」：**从 Excel 复制整块粘贴**，或选 `.csv/.tsv/.txt`

> 注意：**成绩录入与检录不走暂存**（现场多人实时协同，走暂存会互相打架），它们直接生效并推送大屏。
> 编排类改动（名单/赛程/公告/设置）**只有管理员需要确认**，操作员改了直接生效。

### 赛事状态：未开始 → 检录中 → 进行中 → 已结束

| 状态 | 怎么进入 |
| --- | --- |
| **未开始** | 默认；设了开始时间的话到点会自动变「进行中」 |
| **检录中** | 裁判点「开始检录」。**开始检录后状态就不再被时间自动改动**（人工推进优先） |
| **进行中** | ① 检录**人齐了自动变**（这是现场最常用的） ② 到开始时间自动 ③ 手动点 |
| **已结束** | 设了结束时间到点自动；或手动点「标记已结束」（之后可「恢复自动」） |

> **检录要先点「开始检录」才能标到场**。没开始就点会提示"这个项目还没开始检录" ——
> 这样能避免误点，也保证「检录中」这个状态是真的有人在检录。
> 开始/停止检录会**自动在公告栏写一条**，大屏上能看到。

### 现场录成绩（手机直接用，不需要另开页面）

> 原来有一个独立的手机录入页 `/entry`，**已经去掉**：后台本身就适配手机，
> 一个地址就够，少记一个链接、少一处要维护的界面。

- 手机浏览器打开 `http://你的局域网地址:8080/admin` 即可；窄屏下页签横向滑动、表格自己横向滚
- 输入框高度 ≥ 40px；**失焦即提交**，不用找保存按钮；**回车跳到下一个还没录的人**
- 同班成块显示；点名字右边的圆圈标记"已到/未到"
- **断网也能录**：成绩先进本机队列（按账号+届次隔离），联网自动补交；服务端凭唯一 id 幂等去重，不会录成两条。
  顶栏会显示 **「⏳ 待补交 N 条」**，点一下手动重试；**被服务端拒绝的会变红留着**（不会悄悄丢掉）
- 别人先改了同一条：弹出**并排对比**（服务器当前值 vs 我要提交的值 + 是谁改的），由人选用哪个，**绝不静默覆盖**
- 暂存确认同样会查冲突：暂存之后别人改过同一条 → **整体拒绝**并列出"暂存时是什么、现在是什么"，
  要明确选「仍然覆盖」才生效（见 `改动指南.md` 第 63 条）

## 联网与可靠性

- 账号三级：**管理员**（全部，改动需确认） / **操作员**（录成绩、改状态、检录、公告、聊天、名单赛程，改动直接生效） / **只读**
- **一个账号同一时间只能在一台设备上登录**（`config.js` 的 `allowMultiDeviceLogin`，默认 `false`）。
  在别处登录会把原来那台**立刻顶下线**，并明确告诉它原因
  （「这个账号在另一台设备上登录了（IP），当前这台已被下线」）——
  不会莫名其妙"突然要重新登录"。
  **为什么默认只让一台**：共用账号是现场最容易被忽略的出错来源 ——
  两个人用同一个账号各自录成绩，录到同一项目就会互相覆盖。
  要放开就改成 `true`；账号页可以看到每个账号登录在哪台机器，也能把它踢下线。
- 账号页的**「在线」= 最近 90 秒内还在活动**（页面每 30 秒打一次心跳），
  **不是「有过登录记录」** —— 人关掉网页一会儿就显示「已离线（还留着登录）」，
  不会出现"打开过一次就一直显示已登录"。停在账号页会自动刷新。
- 会话用 HttpOnly Cookie + CSRF 令牌；登录失败限流；账号停用或改密后其会话立即失效
- 实时：SSE 推送（**首包是完整快照，之后能发增量就发增量**），断线自动重连，
  长时间不通自动退化为 3 秒轮询；大屏断网时保留最后一次数据并显示「连接中断」（不白屏），
  顶部有**与主机的连接状态**指示。
  增量带 `base`（基于哪个版本），客户端发现对不上就**退回全量** —— 宁可慢一点也不少数据。
  一次录成绩的推送量：后台 1.9 KB（原 296 KB）、大屏 4.8 KB（原 26 KB）
- 名单**不在快照里**，改由 `GET /api/roster` 按需拉（支持服务端筛选与分页）——
  905 人的明细有 209 KB，而录成绩、检录根本用不到它
- 并发写入：每条成绩带 `version`，客户端提交时回传它看到的版本，对不上就拒绝并返回服务器当前值
- 时间一律存 **UTC ISO**，显示时按本机时区换算（服务器时区改了也不会整体错位）

## 数据安全

- 备份：**每 30 分钟**自动检查一次（有改动才备）+ 启动时 + 恢复前 + 手动；
  **只保留最近 30 份**（更旧的自动删除）；备份用 SQLite 官方 backup API（WAL 下也安全）
- 恢复：需要输入「恢复」两个字；恢复前自动把当前数据再备一份；损坏的备份拒绝恢复；防路径穿越
- 导入名单（**兼容性做得比较宽**，现场表格千奇百怪也不会卡住）：
  - 从 Excel 选中整块**复制粘贴**最省事；也能选 `.csv / .tsv / .txt` 文件
  - **分隔符自动识别**：制表符、逗号、分号、竖线都行；带引号的 CSV（字段里有逗号）也正确切分
  - **编码自动识别**：UTF-8（含 BOM）、GBK、UTF-16 都能读 ——
    Excel 直接"另存为 CSV"出来的中文 CSV 是 GBK，以前会变乱码，现在没问题
  - **表头自动定位**：表头前面有几行标题/制表人行也没关系，程序在前 8 行里找「姓名」列最多的那行
  - **列名宽容匹配**：`姓名 / 运动员姓名 / 姓 名* / 学生姓名`、
    `号码 / 号码布 / 参赛号 / 学号 / 编号`、`班级 / 所在班级 / 行政班` 都能认；
    全角、空格、星号、括号里的内容都会自动忽略
  - 只有**姓名**是必须的；其它列没有就用默认值，不会因为少一列整份失败
  - 导入前会给一张**列映射预览表**（哪列认成了什么 + 前 6 行效果）和缺姓名行的提醒
  - `.xlsx` 读不了（压缩包格式，零依赖限制），界面会提示"复制粘贴"或"另存为 CSV UTF-8"
- 导出：Excel（**成绩汇总表**（一行一条，推荐）/ 成绩明细（按项目分表）/ 排名表 / 班级总分榜 /
  名单 / 秩序册 / 检录单）、CSV（带 BOM，中文不乱码）、以及**全量 JSON**（换机器/存档用）
  - 导出的 Excel 已经调好：**冻结表头**（滚动时表头不跑）、**A4 横向打印**、
    号码与成绩是**文本格式**（`001` 不会变成 `1`、`12.30` 不会变成 `12.3`、长号码不变科学计数法）、
    名次与得分是**真数字**（能直接排序求和）、行数多时自动加**合计行**
  - 文件名带**会名 + 表名 + 本机时间**（例如 `校运动会-成绩汇总表-202609251403.xls`），
    一天导好几次也不会互相覆盖
- 操作记录：谁在什么时候改了什么；成绩类改动可查可追
- 危险操作（清空数据、载入演示、恢复备份）都要**输入指定文字**确认

## 已知限制（如实说明）

1. **零依赖的代价**：数据库用 Node 22.5+ 内置的 `node:sqlite`，所以 **Node 版本必须 ≥ 22.5**。
   换 `better-sqlite3` 只需改 `src/db.js` 一个文件。
2. **导入名单**：读不了 `.xlsx`（那是压缩包格式，零依赖读它要引第三方库）。
   界面会明确提示：**从 Excel 复制整块粘贴**（最省事），或「另存为 → CSV UTF-8」再选文件。
   其它表格格式的兼容性做得比较宽（分隔符/编码/表头位置/列名别名都自动处理，详见上文"导入名单"）。
3. **口令很弱**：现在用的是 `admin123` / `aaa123`，好在校园局域网内部用。
   **如果这台电脑还接了外网（公网 IP、端口映射），请务必换成复杂口令**，
   或干脆在运动会结束后把服务关掉。改口令：双击「重置口令.bat」。
4. **SQL 静态自检有漏报**：SQL 写成变量、拼接的 `DELETE`/`SELECT` 查不出来（详见 `tools/sql-check.js` 文件头）。
5. **大屏的实时验证**是静态快照模式（`?static=1`）：真实 SSE 推送需要人手在大屏上看；
   自动化只验"版面与内容渲染正确"。这是无头浏览器的固有限制。
6. **`--window-size` 与实际视口有偏差**：无头浏览器会扣掉一点窗口装饰，
   所以体检报告里的实际视口比参数小几十像素（例如 1920×1080 → 1880×961）。这是环境行为，不是页面问题。
7. **聊天室附件**存在 `data/uploads/`，只走局域网；没有做内容审核，靠现场自律。
   **只能发图片**（按扩展名白名单 + 文件头魔数双重核对），
   HTML/SVG 这类"能被浏览器当网页打开"的文件一律拒收，
   `/uploads/` 的响应带 `nosniff` 与 CSP `sandbox`。
   **没有语音**：浏览器要求录音跑在安全上下文里，而现场是 `http://192.168.x.x`，
   手机上拿不到麦克风（服务器本机 `localhost` 是例外，所以本机能录、手机不能 ——
   这种"本机好使、现场不行"的功能不如不做）。要用语音得先给局域网配 HTTPS。
8. **单机部署**：这一版按"学校局域网一台电脑当服务器"设计，没有多赛区/多场地分片；
   几百人、几十个项目、十几个并发录入完全够用，规模再大要换 PostgreSQL 并加分片。
